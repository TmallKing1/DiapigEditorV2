# Diapig Editor

Diapig Editor 是面向原神千星奇域创作者的 Windows 桌面工具。你可以编辑对话和任务链、预览对话分支，也可以处理图片、生成像素画，或请 AI 协助编写对话。

## 下载与安装（Windows 64 位）

[下载 Diapig Editor](https://github.com/TmallKing1/DiapigEditorV2/releases/latest)

在发布页的「Assets」里选一个文件下载。

- `DiapigEditor-2.0.1-windows-x64-setup.exe`：安装版，下载后按向导完成安装即可使用。
- `DiapigEditor-2.0.1-windows-x64-portable.exe`：免安装版，下载后直接打开就能运行。

## 使用文档

- [开始使用](docs/开始使用.md)：编辑和保存对话与任务链，解决常见的保存问题。
- [图片与像素画](docs/图元拟合图片约定.md)：使用「图元拟合」与「像素画生成」，按需导出 PNG 或 Lua 文件。
- [和 AI 一起写对话](docs/对话草稿格式.md)：与 AI 协作拟定对话草稿并整理为可打开的对话文件。
- [让 AI 直接修改对话文件](docs/对话MCP服务.md)：在已连接对话工具的 AI 客户端中直接检查与修改对话文件。
