# 图片与像素画

在「更多」页面中，你可以使用「图元拟合」和「像素画生成」两个工具，把普通图片转换为适合在千星奇域中展示的画面资源。

## 图元拟合

「图元拟合」会把一张图片用基础图形组合还原，并导出为可在游戏里显示的 Lua 数据。

1. 进入「更多」，打开「图元拟合」。
2. 点击「选择图片」，从本地选定需要处理的图片。
3. 首次尝试可以先保持默认设置，直接点击「开始拟合」。
4. 拟合完成后，在界面中对比原图与生成结果，确认轮廓和色彩是否满意。
5. 如果需要调整效果，可以调整「图元数量」或开启「保留透明度」后重新拟合。图元数量越多，画面通常会更细致，拟合耗时也会相应增加。
6. 确认效果后，点击「导出 Lua」。
7. 需要将结果接入游戏项目时，把导出的 Lua 文件和点击「复制 Agent 提示词」获得的内容一起交给负责接入的协作者即可。

## 像素画生成

「像素画生成」可以把图片转换为像素风格画面，并在预览后按需导出。

1. 进入「更多」，打开「像素画生成」。
2. 点击「选择图片」，打开要转换的图片。
3. 设置「宽度」和「高度」，然后点「生成」。改变宽高比例会拉伸图片。
4. 在预览区域查看像素画效果，如果不满意可以调整宽高后重新生成。
5. 确认无误后，点「导出 PNG」或「导出 Lua」。

## 什么时候选 PNG 或 Lua

想把结果当普通图片查看、编辑或分享，就选 PNG。需要让协作者在千星奇域玩法里显示这张图，就选 Lua。
