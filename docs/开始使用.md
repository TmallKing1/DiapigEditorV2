# 开始使用

打开 Diapig Editor 后，你会进入「主页」。你可以按自己的创作目标新建或打开文件，编辑完成后再保存并导入游戏确认效果。

## 打开、新建与保存文件

1. 在「主页」切换「对话」或「任务」页签，选择当前要处理的内容类型。
2. 点击「新建对话」或「新建任务链」开始，也可以点「导入文件」打开已有文件。
3. 当工作区里已有文件时，文件区域会显示「新建」「导入」「设置」按钮，方便你随时切换文件或调整当前文件的设置。
4. 之前编辑过的文件会记录在「历史文件」中，需要继续修改时可以直接从这里重新打开。
5. 修改完成后，点击「保存」覆盖当前文件，或点击「另存为」保存成一份新文件。

## 编辑与预览对话

在「对话」页签中，对话内容按列表顺序排列。

- 逐条填写或修改说话人与对话内容。
- 需要让玩家做出选择时，为对应节点添加选项分支，或直接设置跳转去向。
- 编辑完成后，点击「预览对话」，按玩家视角完整走一遍各条分支，检查文字、选项和跳转是否顺畅。
- 确认无误后点击「保存」或「另存为」。

编辑器里的「预览对话」用于提前检查流程和文本，实际显示效果、触发时机和交互表现需要在游戏里最终确认。

## 编辑任务链

在「任务」页签中，你可以维护一条完整的任务链。

- 填写每个任务的名称与说明，并按流程需要调整任务顺序。
- 任务链的完成事件需要在当前任务文件所属的「设置」中填写和核对。
- 调整完成后点击「保存」或「另存为」，随后到游戏里确认实际运行效果。

## 无法保存与结构体 ID 检查

如果保存时提示缺少「结构体 ID」，按下面的步骤核对。

1. 点击当前文件区域的「设置」，查看里面的「结构体 ID」是否填写完整。
2. 从游戏编辑器导出的匹配文件在「导入文件」或「导入」时会自动带出对应的结构体 ID，直接基于这类文件编辑可以省去手动填写。
3. 如果导入旧对话时提示缺少「对话起止设置结构体」，请先在游戏编辑器中准备好新版结构，把游戏里实际对应的结构体 ID 填入当前文件的「设置」，再逐项核对其余结构体 ID。
4. 结构体 ID 必须与游戏编辑器中的实际数值保持一致，不能凭感觉猜测或随意填写。
5. 保存修改时可以用「另存为」写入新文件，方便保留原件。

## 「更多」里的辅助工具

在「更多」页面中，除了图片处理工具外，还提供以下辅助功能：

- 「富文本编辑」：用于整理带格式样式的文本内容。
- 「成长曲线」：用于规划和调整数值变化曲线。
- 「评论抓取」：填写「关卡 GUID」，选好评价类型，再点「开始抓取」查看玩家反馈。

## 离线切换原神输入设备

如果需要在进入游戏前切换键鼠与手柄等输入设备，可以使用离线切换功能：

1. 先完全退出国服原神客户端，避免配置在运行中被覆盖。
2. 在软件的「设置」中进入「更多」页，找到「原神输入设备切换」卡片。
3. 点击「切换输入设备」，选中本机登录过的游戏账号，核对当前模式后确认切换。
4. 软件会在切换前保存一份备份。下次启动游戏时使用切换后的输入模式。
